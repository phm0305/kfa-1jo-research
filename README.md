# 1조 리서치 센터

KFA AI 에이전트 스터디 1조의 레포입니다. 공통 엔진이 DART에서 재무와 사업보고서를 모으고 숫자를 계산·대조하며, 조원은 각자 자기 파트의 지시서만 고쳐서 리포트를 고도화합니다.

- 작업 규칙, 실행 방법, 키 준비: [AGENTS.md](AGENTS.md)
- 내 PC 설치: `py -m pip install -r requirements.txt`
- 내 폴더: `members/industry`, `members/company`, `members/valuation`, `members/center`
- Colab 실행: `notebooks/research_center.ipynb`

## 웹 채팅(Claude.ai, ChatGPT)만 쓰는 경우

아래 글을 첫 메시지에 붙여넣고, 이어서 내 지시서 파일(`members/<내 파트>/prompts/<내 파트>.md`) 내용 전체를 붙여넣으세요. 고친 결과는 GitHub 웹에서 같은 파일에 덮어써서 올립니다.

```
나는 증권사 리서치 리포트를 만드는 AI 파이프라인에서 한 파트의 지시서를 고도화하고 있어.
곧 붙여넣을 지시서를 고쳐 줘. 규칙:
1. 맨 위 --- 두 줄 사이의 머리말은 "파트", "리포트 칸", "데이터", "소제목" 네 가지만 쓰고, 값의 모양은 지금 그대로 둬. "소제목"은 없어도 되고, 쓸 때는 "소제목: {5쪽: [C-1, C-2, C-3, C-4]}"처럼 리포트 칸에 적은 쪽마다 소제목 목록을 적어. 본문에서 JSON 키나 소제목을 말할 때는 이 목록과 글자 그대로 같게 써.
2. 본문에서 쓸 수 있는 빈칸은 {종목명} {종목코드} {연도} 세 개뿐이야. 다른 중괄호를 만들지 마.
3. 숫자는 코드가 준 데이터 묶음에서만 나와. 지시서에 숫자를 직접 적거나 계산하라고 시키지 마.
4. 데이터 묶음에 없는 자료가 필요하면 지시서에 넣지 말고, 엔진 요청서에 적을 내용(필요한 데이터, 왜 필요한지, 어느 칸에 쓸지)을 따로 알려 줘.
5. 다 고치면 파일 전체를 한 번에 보여 주고, 바꾼 점을 3줄 이내로 요약해 줘.
```
