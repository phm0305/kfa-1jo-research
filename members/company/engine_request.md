# 기업·재무분석 엔진 요청서

기업·재무분석 3쪽에서 사업구조, 실적 변화, 이익의 지속 가능성, 향후 실적 변수를 설명하는 데 필요한 추가 데이터와 출력 기능을 요청합니다.

| 필요한 데이터·기능 | 필요한 이유 | 사용할 리포트 위치 |
|---|---|---|
| **영업부문 공시 수집 범위 확대** — 이미 제공되는 품목 매출과 지역 외부매출·부문영업손익은 재사용하고, 공시돼 있지만 추출되지 않는 사업부별 외부매출·부문 손익과 연결 조정 내역을 추가. 분류 축, 외부·내부거래, 합계·조정 행을 구별하고 같은 분류·기간의 외부매출 합계를 식별. | 제품·지역·사업부 간 중복 합산을 피하고, 매출 비중과 이익 기여를 구분. | 3쪽 상단 사업구조 |
| **최신 누적 실적과 원인 근거** — 최신 누적과 전년 동기 누적의 연결 손익을 기간 시작·종료일, 공시일, 정정 여부와 함께 제공. 판매량·가격·제품 구성·실제 투입 원가·연결 범위 등 공시나 공식 IR의 설명을 해당 기간과 사업·계정에 연결. | 같은 기간의 실적을 비교하고, 이익 변화의 원인과 단순 동시 변화를 구분. | 3쪽 중앙 최신 실적 비교와 변화 원인, 하단 향후 실적 변수 |
| **현금흐름·차입금·일회성 손익** — 연간과 비교 가능한 누적 영업현금흐름, 주요 운전자본·비현금 조정, 현금성자산, 차입금 잔액·만기, 이자 부담, 유형·무형자산 취득 현금 지출을 제공. 공시된 일회성 손익에는 발생 사유, 반영 계정, 세전·세후 범위를 표시. | 같은 기간의 순이익과 현금 창출을 비교하고 본업 성과, 일시적 손익, 상환·투자 부담을 구분. | 3쪽 하단 재무 안정성과 이익의 지속 가능성 |
| **금융업 특화 공시 지표** — 공시가 있는 경우 업종에 맞는 자본적정성·자산건전성·수익성 지표의 값, 정의, 기준 시점과 적용 범위를 제공. | 금융회사 이익의 지속성과 재무 위험을 업종에 맞는 기준으로 설명. | 3쪽 중앙 수익성, 하단 재무 안정성 |
| **검증 가능한 추가 코드 지표** — 동일 분류·범위의 부문 외부매출 비중, 동일 기간 손익의 증감액, 이익 증감률, 이익률 차이(%p)를 본문이 인용할 수 있는 지표 행으로 제공. 조정 이익은 공시 근거와 반영 범위를 특정할 수 있는 경우에 한해 산출. 각 지표에 출력 단위, 산식, 입력 행 ID와 계산 보류 사유를 포함. 비교 기준 이익이 0 이하이거나 흑자·적자가 전환되면 증감률은 제공하지 않고, 증감액과 전환 상태를 제공. | 본문에서 새로 계산할 필요 없이 표·차트와 같은 값을 인용하고 숫자 대조에서 원본까지 추적. | 3쪽 사업구조·실적 비교·이익의 질 |
| **3쪽 전용 실적 추이 차트·최신 실적 소표·A4 인쇄 배치** — 차트는 비교 가능한 최근 완료 회계연도를 공통 가로축으로 두고 실적 규모(억원)와 수익성(%)을 독립 패널에 표시. 비교 가능한 연도가 두 개 이하이면 소표 사용. 기존 2개년 비교표에 최신 누적·전년 동기 비교와 핵심 행 선택을 추가하고, 동기 비교가 불가하면 연간임을 표시. 차트 결측은 선을 끊고 소표에는 빈값과 사유를 표시. 두 자료 모두 기간·단위·회계 범위·출처를 표시하고, 인쇄 시 핵심 행과 시각 자료를 선별해 가독성을 유지하면서 본문과 함께 A4 세로 한 쪽에 배치. | 여러 해의 방향과 최신 변화의 크기를 한 페이지에서 읽고, 본문과 시각 자료의 값·증감 방향을 교차 점검. | 3쪽 중앙 시각 자료와 하단 출처 |

새 원본 행과 계산 행은 공통 데이터 규격에 맞춰 기간, 회계 범위, 값·단위, 원본 출처와 실제 근거 ID를 제공합니다. 미공시·수집 실패·비교 불가·계산 불가는 사유를 구분하고 결측을 0으로 대체하지 않습니다.
