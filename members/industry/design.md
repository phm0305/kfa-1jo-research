# 산업 파트 설계 메모 (사람용, AI는 읽지 않음)

11/22 피드백("AI가 읽을 것만 지시서에, 엔진·사람용 내용은 분리")에 따라 지시서 `prompts/industry.md`에서 옮겨 온 내용이에요. 엔진 담당·조원이 참고하는 설계 문서이고, 엔진에 실제로 요청할 데이터는 `engine_request.md`에 단계별로 정리돼 있어요.

## 1. 원래 설계한 분석 순서

범위 확인(금융업) → 산업 정하기(업종코드) → 유형 분류 → 산업 데이터 요청(유형별 지표) → 동종사 정하기 → 분석·작성(국면 → 영향 요인·마진 결정 요인·구조 변화 → 경쟁 구도). 이 중 "데이터 요청"과 "동종사 정하기"는 AI가 아니라 엔진이 할 일이라 지시서에서 뺐어요.

## 2. 판단 기준 중 엔진·계산 도구 몫

- 사이클 국면: 주 지표의 3개월 기준 YoY가 양(+)·상승 = 확장 / 양(+)·하락 = 둔화 / 음(−)·상승 = 회복 / 음(−)·하락 = 침체. 단월 숫자는 출렁임이 커서 국면이 매달 뒤집힘
- 직전 대비 ±5%p 이내 변화는 "방향 없음"으로 보고 직전 국면 유지. SK하이닉스 시험에서 수출 YoY 262.8% → 259.4%(3.4%p 하락)만으로 "둔화"가 나온 오판 때문
- YoY가 +100%를 넘으면 "기저효과 주의"와 전년 고점 대비 수준을 함께 표시
- 경고 신호: 주 지표(양)는 확장인데 보조 지표(질)는 둔화, 또는 매출은 늘고 영업이익률은 하락
- 매출↑·이익률↓이면 비용 비율(광고선전비·운반비·수수료 등) 중 가장 많이 오른 항목을 원인 후보로
- 동종사와 규모 차이가 10배 이상이면 비교에서 제외

## 3. 계산 규칙 (계산은 코드가 함)

- 3개월 YoY = (최근 3개월 합 − 전년 같은 3개월 합) ÷ 전년 같은 3개월 합
- 국면 = 3개월 YoY의 부호 × 직전 대비 방향 (±5%p 이내는 직전 국면 유지)
- 기저효과 표시 = 3개월 YoY > +100%면 표시, 전년 고점 대비 %도 계산
- 업종 매출 성장률 = 동종사 매출 합의 YoY / 5년 CAGR = (마지막 해 ÷ 첫 해)^(1/5) − 1
- 상장 동종사 내 비중 = 대상 매출 ÷ 동종사 매출 합 ("시장 점유율"이 아님)
- 영업이익률 = 영업이익 ÷ 매출
- 설비투자 강도 = 유형자산 취득액 ÷ 매출
- 수출 단가 = 수출액 ÷ 수출중량 (관세청)
- 광고선전비/매출(CAC 대용), 운반비/매출, 지급수수료/매출, 감가상각비/매출
- Take-rate = 커머스 매출 ÷ 거래액 (IR 거래액 필요)
- 마진 원인 후보 = 매출 YoY > 0이고 영업이익률 하락이면, 비용 비율 중 전년 대비 가장 많이 오른 항목
- 동종사 규모 필터 = 대상 매출 대비 10배 이상 차이 나는 회사는 비교 제외

## 4. 원래 희망한 데이터 범위

- DART 숫자(연결): 대상+동종사 매출·영업이익·유형자산 취득액 5개년, 판관비 주석(광고선전비·운반비·지급수수료·감가상각비) 2개년, 업종코드와 같은 업종 상장사 목록
- DART 글: 사업의 내용(사업 개요, 제품별 매출 비중)
- 산업·거시 통계: 관세청 HS코드별 수출액·중량, KOSIS 광공업동향·온라인쇼핑동향·소매판매액지수·서비스업생산지수, 방송통신광고비, ECOS 기준금리·환율·CSI (모두 월별 10년)
- 출처카드: 증권사 산업 리포트, 시장조사기관, 회사 IR, 해외 경쟁사 공시, 뉴스·정책 자료(기사 속 숫자는 쓰지 않음)

## 5. 다른 파트와 주고받기

- 받는 것: 엔진(업종코드, 재무, 통계), 계산 도구(지표·국면), 숫자 대조(통과/확인 필요/수정)
- 넘기는 것
  - 기업·재무: 산업 결론 한 줄(유형·추세·핵심 변수), 동종사 목록, 동종사 평균 마진. 이익 추정은 기업·재무가 함
  - 밸류에이션: 동종사 목록, 산업 유형과 국면(경기민감형이면 지표 선택에 참고)
  - 센터장: 산업 결론 한 줄, Key chart 후보, "파트 간 충돌" 목록
  - 검증관: 유형 분류 근거
- 실행 순서: 엔진 → 산업 → 기업·재무 → 계산 도구 → 밸류에이션

## 6. 모임에서 확인할 점·고민 중

- 양식은 "유형 분류 → 산업 정하기" 순서인데, 업종코드로 산업을 먼저 정하고 유형을 분류하도록 바꿈
- 산업은 업종코드 1개로 정함. 겸업 기업(NAVER, 삼성전자 등)은 "업종코드 밖 사업"으로 표시만. 엔진이 부문 매출을 수집하면 부문 기준으로 확장 가능
- 금융업 유형: 지금은 규제·인프라형으로 분류하게 함. 금감원 금융통계 등 새 소스가 생기면 별도 유형 검토
- 기준값(±5%p, +100%, 10배, 성장형 CAGR 기준)은 초기값. 여러 종목에 돌려 보고 조정
- 해외 경쟁사(구글, 쿠팡, 마이크론 등) 데이터를 어떻게 넣을지

## 7. 시험 결과

- 네이버: 업종코드(포털)에 커머스가 안 잡힘 → "업종코드 밖 사업" 표시 규칙, 플랫폼·광고형 추가
- SK하이닉스: 국면 오판(3.4%p 하락으로 "둔화") → 3개월 기준·±5%p 밴드·기저효과 표시 추가
- 농심(11/22): 산업 통계가 묶음에 없어 "판정 불가"가 제목에 들어가고 회사 숫자 위주로 씀 → 묶음에 있는 발췌 숫자로 쓰게 하고, 유형은 반드시 정하게 함

## 8. 11/23 변경 (개발자 피드백 반영)

- 산업은 업종코드 1개가 아니라 **실제 주력 사업**(업종코드 + 주요 사업 + 매출 비중 세 가지)으로 정함. 업종코드와 다르면 차이를 본문에 표시
- "경기순환형" 이름을 "경기민감형"으로 바꿈
- 지시서의 분석 순서를 6단계(기업·산업 파악 → 유형 → 성장·국면 → 성장 요인·수익성 → 경쟁 → 작성)로 나눔. 엔진은 산업 파트를 한 번만 부르므로, 단계 사이에 데이터를 새로 받는 2회 호출은 엔진 구조 변경이 필요해 지시서 안의 순서로만 나눔
- 지시서에서 뺀 것: "같은 문장이 숫자 대조에서 3번 걸리면 미확인"(코드가 하는 일), "기업·재무 결론과 충돌 표시"(산업이 먼저 실행돼 볼 수 없음. 센터장 쪽 규칙으로 제안)
