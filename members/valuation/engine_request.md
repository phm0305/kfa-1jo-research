## 독립 검증에서 해결한 항목

- **공시 EPS 차이 원인 확인 완료.** 농심 2025년 연결감사보고서 주석 34로 분자와 가중평균 유통보통주식수를 확인했고 공시값을 재현했다. 공통 엔진의 주석 필드 자동 전달은 P0에 남긴다.
- **농심 검증용 종가 확보.** 2026-11-19 종가 342,000원을 공개 시세 자료에서 확보해 시장 지표와 괴리율을 계산했다. 공통 엔진의 공식 종가 조회·전달은 P0에 남긴다.
- **농심 검증용 전망과 비교 배수 확보.** 독립 계산에는 증권사 자료의 2027년 추정치를 별도 JSON으로 입력했다. 가격 기준일을 맞춘 비교기업 배수의 엔진 제공은 P1에 남긴다. 통합 실행에서는 밸류에이션의 자체 전망 가정과 출처·기간을 전달하는 경로가 필요하다.

## 공통 데이터 반환 원칙

1. 기존 엔진 스키마를 우선 유지하고, 필드 추가는 엔진 담당과 합의한다.
2. 원자료와 파생값을 구분하고 `단위`, `실적기간`, `실제 공개시각`, `가격 기준일`, `연결/별도`, `출처 ID/URL`, `수집 경로`를 추적 가능하게 한다.
3. 원천 신뢰도와 수집 경로(L1 공식 API / L2 라이브러리 / L3 파일 / L4 크롤링 / L5 수동)를 별개 필드로 기록한다.
4. 계산된 지표에는 `formula`, `input_metric_ids`, `calculation_version`을 남겨 검증관이 재계산할 수 있게 한다.
5. 평가일 정규장 종가 산출 이후에 공개된 재무 수치는 해당 시점의 평가에 사용하지 않는다.
6. 결측은 `null`과 사유로 표시한다. 5개년을 채우기 위해 확인되지 않은 연도를 만들지 않는다.
7. API 키 값은 요청서와 로그에 기록하지 않는다.

## 리포트 4쪽 표·그래프 출력 요청

- **문제** — 공통 HTML 렌더러는 Markdown 문단과 불릿을 처리하지만 표 문법을 HTML 표로 변환하지 않는다. 이 때문에 5개 모형 판정표, 동종기업 비교표, Bear/Base/Bull 가치평가표가 웹 리포트에서 표로 표시되지 않을 수 있다.
- **생성 단계의 충돌** — 공통 출력 규칙이 파트 지시서 뒤에서 표·차트를 `표 필요` 문구로 바꾸도록 지정한다. 실제 4쪽에서 표를 내보낼 수 있도록 이 규칙에 밸류에이션 예외를 두거나 구조화된 출력 항목을 제공해야 한다.
- **요청 사항** — 공통 실행이 생성한 `report.html`의 밸류에이션 탭에서 5개 모형 판정표, 동종기업 비교표, Bear/Base/Bull 가치평가표를 실제 HTML 표로 표시하고, 유효한 종가 시계열이 있으면 주가 추이 그래프를 표시해 달라고 요청한다. 밸류에이션에 실제 표를 허용하고 Markdown을 변환하거나, 공통 계산 결과를 구조화해 템플릿이 직접 그리는 방식을 검토해 달라고 요청한다.
- **완료 기준** — 공통 실행 한 번으로 기존 4쪽에 표·그래프가 표시된다. 표의 행·열 순서, 숫자, 단위, 미산출 사유가 원본과 일치하고 문단·불릿 출력도 유지된다. 종가 시계열이나 계산값이 없으면 해당 영역에 결측 사유를 표시한다.
- **구현 참고** — `valuation.details`는 종가 시계열(`date`, `close`)과 비교기업·전망·가치평가 결과를 전달할 때 검토할 수 있는 제안 필드명이다. 현행 공통 템플릿에는 이 필드의 처리 기능이 없다. 로컬 검증에서는 저장된 리포트의 복사본에 별도 표시 코드를 적용했다.
