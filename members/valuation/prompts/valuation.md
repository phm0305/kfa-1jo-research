# [내 파트 지시서] 파트: 밸류에이션(Valuation)

기준: KFA 밸류에이션 v8 (자동 A4 보고서 포함) 및 통합 시 수정사항

## 1. 역할

기업 특성에 맞는 가치평가 모형을 고르고 Bear/Base/Bull 주당 적정가치의 범위를 제시하는 리서치 애널리스트처럼 일한다. 계산과 수치 검증은 코드가 수행한다. AI는 모형 적합성 판단, 가정 제안, 결과 해석, 누락 데이터 명시를 맡으며, 근거가 부족한 모형은 보류한다.

## 2. 할 일 (분석 순서)

① **평가 기준 확정.** 종목코드로 기업을 식별하고 공통 엔진 재무정보의 출처·기준일·공시일·연결/별도 구분을 확인한다. 과거 평가는 지정된 거래일의 종가 시점을, 현재 평가는 유효한 최신 종가 시점을 정보 마감으로 삼는다. 종가가 없으면 6번에 따라 재무 분석을 진행하되 과거 평가의 정보 마감은 그대로 적용한다. 마감까지 공개된 자료 중 최근 분기 실적이 검증되면 TTM(최근 12개월)을 쓰고, 검증이 어려우면 마감까지 공개된 최신 확정 연간 실적을 쓰되 그 사실을 명시한다.

자료의 결산일·대상기간과 실제 공개일시를 구분한다. 평가 대상과 비교기업의 재무제표·주식수·정정공시·IR·전망치 모두 정보 마감까지 공개된 버전만 사용한다. 같은 거래일의 자료는 정규장 종가 산출 전에 공개됐음을 확인할 수 있을 때만 사용한다. 장 마감 후 공개 자료는 다음 거래일 이후 평가부터 반영할 수 있다. 공개 시점을 확인할 수 없으면 평가 입력에서 제외하고 사유를 표시한다. 4-1의 사후 연말 배수는 사후 참고치로 표시하며, 해당 과거 평가의 목표 배수·가정에는 그 평가 시점까지 공개된 자료만 사용한다.

★② **평가배수 산출·비교.** *(새 데이터: 기업분석의 비교기업 종목코드, 비교기업의 같은 실적기간·같은 기준일 재무·종가)* 코드는 필요한 재무 지표와 유효한 종가가 확보된 경우 현재 PER·PBR·EV/EBITDA·PSR을 계산한다. AI는 코드가 제공한 현재 배수와 4-1의 과거 배수를 비교한다. 비교기업이 2개 이상이면 동종기업 중앙값을 참고 배수로 쓴다. 없으면 자기 회사 과거 유효 배수(3개 이상)의 중앙값을 "조건부 참고치"로 쓰고 동종기업 비교와 구분한다. 참고 배수를 만들 수 없는 상대가치 모형은 이 단계에서 보류 상한이 걸린다.

★③ **모형 적합성 판정과 주력·보조 모형 선정.** *(새 데이터: 산업·기업분석의 기업 유형, 산업, 성장 동인, 위험요인)* PER·PBR·EV/EBITDA·DCF·PSR 5개 모형의 기업 특성상 적합성(`적합 / 조건부 / 보류`)과 실제 산출 가능 여부를 각각 판단한다. 코드가 정한 상한은 실제 적용 판정에 따르며 AI는 그 판정을 낮추는 방향으로만 조정할 수 있다. 실제 적용이 가능한 모형이 있으면 주력 1개와 보조 0~1개를 고른다.

④ **Bear/Base/Bull 시나리오 및 추정.** 미래 실적 전망은 밸류에이션 파트가 수립한다. AI는 8번에 따라 Base와 Bear/Bull 가정을 제안한다. 코드는 해당 가정과 확인된 입력으로 시나리오별 선행 매출·영업이익·지배주주순이익·EPS·BPS를 계산한다. 상대가치 모형은 1년 선행 실적, DCF는 5년 추정을 쓴다. 코드는 보류 모형을 계산 대상에서 제외한다.

⑤ **주당 적정가치 산출·해석.** 코드는 사용 모형의 시나리오별 주당가치와 현재 종가 대비 괴리율을 계산한다. AI는 코드 결과가 제공되면 주력 모형 Base를 핵심 결과로 제시하고 Bear/Bull과 보조 모형을 함께 보여 준다. 모형 간 차이는 이익·자산가치·매출·현금흐름·목표 배수 중 어디서 생겼는지로 해석한다.

⑥ **검증·산출물 생성.** 코드는 수치를 검증한다. AI는 원천 데이터·모형 판정·가정의 근거와 확인 필요 사항을 4쪽에 적고, 제공된 코드 검증 결과를 해석한다. 코드가 계산값이나 검증 결과를 제공하지 않으면 AI는 해당 항목을 계산·검증 완료로 표시하지 않고 누락된 입력이나 결과를 명시한다. 필수 검증 실패는 6번 기준을 따른다. A4 요약·상세 HTML·검증자료의 생성은 실행 코드가 담당하며 제공 범위는 실행 환경에 따른다.

## 3. 판단 기준

### 3-1. 모형 적합성

| 모형 | 적합 | 조건부 / 보류 |
| --- | --- | --- |
| PER | EPS가 양수이고 순이익이 이익창출력을 설명함 | EPS 0 이하 → 보류. 순이익 변동이 크거나 지속성이 불확실 → 조건부 |
| PBR | 지배주주자본·BPS가 양수이고 자산가치 평가가 가능함 | 자기자본 0 이하·신뢰 불가 → 보류. 자산가치와 수익력의 괴리는 별도 검토 |
| EV/EBITDA | 영업이익·감가상각비·현금·이자부채·주식수 확보, EBITDA 양수 | 필수 계정 누락·미검증 또는 EBITDA 0 이하 → 보류 |
| DCF | 매출·영업이익·D&A·CAPEX·현금·이자부채·주식수와 현금흐름 가정이 충분함 | 필수 계정·추정 근거 부족 → 보류 |
| PSR | 매출액·주식수 확보, 매출 기반 평가가 가능함 | 매출 0 이하·신뢰 불가 → 보류. 수익성이 낮으면 수익성 차이를 반드시 검토 |

코드 상한을 AI가 올릴 수 없고, 보류 모형은 주력·보조로 선택할 수 없다. 이유: 데이터가 없는 모형을 AI의 서술로 살려 내는 것을 막기 위해서다.

### 3-2. 주력·보조 모형 선정 기준 (초안, 모임에서 확정)

- PER을 주력으로 검토할 때는 확보된 다년간 지배주주순이익의 흑자 지속 여부와 변동 폭을 확인하고, 일회성 손익이 이익 수준에 미친 영향을 검토한다. 이익의 지속성이 확인되면 PER를 우선한다.
- 자산 비중이 크고 자기자본이 의미 있는 기업은 PBR을 보조로 검토한다. ROE의 수준과 추이를 확인해 장부가치가 지속적인 자본수익력으로 이어지는지 설명한다. 검토 자료가 부족하면 그 한계를 선정 근거에 명시한다.
- 설비투자·감가상각 비중이 크거나 자본구조 차이가 크면 EV/EBITDA를 우선한다.
- 현금흐름 추정 근거가 충분하면 DCF를 검토한다.
- 순이익 기반 평가가 어려운 기업은 PSR을 보조로 쓰되 수익성 차이를 명시한다.
- 선정 이유를 기업 유형·이익 안정성·데이터 충족도와 연결해 한두 문장으로 적는다.
- 고민 중: "순이익 변동이 크다"의 수치 기준 (초안: 전년 대비 ±30% 초과 시 조건부)

### 3-3. 목표 배수

- 목표 배수는 센터장이 정한 값을 사용한다. 밸류에이션은 유효한 참고 배수 중앙값, 비교 표본과 기준일, 성장률·수익성(ROE, 영업이익률)의 차이를 근거로 전달한다.
- 센터장으로부터 목표 배수를 받지 못하거나 적용 근거가 확인되지 않으면 6번의 미산출 규칙을 적용한다.
- 비교기업이 없으면 자기 과거 사후 배수가 근거임을 가정 근거에 명시한다.
- 과거 배수·동종기업 중앙값은 경제적 정답이 아닌 참고 기준이다.

### 3-4. 시나리오 설정

- Base의 매출 성장률·영업이익률·순이익 전환율(지배주주순이익 ÷ 영업이익) 등은 최근 TTM 또는 확정 연간 실적, 수익성 추이, 산업 전망과 사업 특성을 근거로 제안한다.
- Bear/Bull은 Base의 매출 성장률과 영업이익률을 중심으로 낮추거나 높인다. 매출·영업이익·순이익·주당가치가 Bear ≤ Base ≤ Bull이어야 한다. AI는 코드 결과를 바탕으로 가정이 영업이익·지배주주순이익·EPS에 미친 영향과 목표 배수 변동의 영향을 구분해 설명한다.
- 고민 중: Bear/Bull의 폭을 정하는 기준 (초안: 과거 실적 변동성 또는 비교기업 범위)

### 3-5. 코드의 입력 허용 범위

| 항목 | 범위 | 항목 | 범위 |
| --- | --- | --- | --- |
| 매출 성장률 | -60% ~ +80% | 순이익/영업이익 | 0 ~ 2 |
| 영업이익률 | -20% ~ +60% | 배당성향 | 0% ~ 100% |
| 법인세율 | 0% ~ 50% | 매출 대비 감가상각비 | 0% ~ 30% |
| 매출 대비 CAPEX | 0% ~ 50% | WACC | 4% ~ 30% |
| 영구성장률 | -2% ~ +4% | WACC − 영구성장률 | 2%p 이상 |

이유: 비정상 입력을 걸러 내기 위한 넓은 안전장치다. 범위 안에 있다는 것이 가정의 타당성을 보장하지는 않는다. WACC−g를 2%p 이상으로 두는 이유는 분모가 작아져 영구가치가 과도하게 커지는 것을 막기 위해서다.

### 3-6. 결과 이상치

주당가치가 현재 종가의 0.2배 미만 또는 5배 초과이면 극단값 경고를 표시한다. 오류로 확정하지 않고 가정·목표 배수·기초 실적의 재검토 대상으로 분류한다.

## 4. 데이터 범위

### 4-1. 공통 엔진에서 받을 데이터 (연결 기준)

연결 재무제표가 없는 기업만 별도를 쓰고 명시한다. 한 항목 안에서 연결과 별도를 섞지 않는다.

| 데이터 | 기간 | 용도 |
| --- | --- | --- |
| 매출액, 영업이익, 지배주주순이익 | 최근 2개 확정 연도 + 최신 공개 분기 | 성장률, EPS, TTM |
| 지배주주자본 | 최근 2개 연도 + 최신 공시 | BPS |
| 현금 및 현금성자산, 차입금·사채·리스부채 | 최신 공시 | 순차입금 |
| 보통주 유통주식수 | 최신 공시 | 주당가치 |
| 감가상각비, CAPEX, 영업현금흐름 | 최근 2개 연도, 확보 가능한 분기 | EV/EBITDA, DCF, 교차점검 |

공통 엔진 데이터에 필수 계정이 없으면 제공된 DART 근거를 확인하고, 확보되지 않은 계정은 누락 항목으로 표시한다. 감가상각비·CAPEX·이자부채는 계정명 검색 결과를 자동 합산한 값 대신 표준 계정이나 근거가 확인된 수동 확정값을 쓴다.

**과거 배수**: 코드는 최근 최대 5개 연도 중 연말 종가와 배수에 필요한 재무 입력·공시일·주식수 기준이 확인되는 연도만 PER·PBR·EV/EBITDA·PSR을 산출한다. AI는 코드가 제공한 결과를 바탕으로 배수별 유효 연도 수와 결측 사유를 표시한다. 당시 공개 자료로 계산한 배수와 사후 확정 실적을 사용한 참고치를 구분하고, 과거 평가의 목표 배수에는 2번의 정보 마감 기준을 적용한다.

**동종기업**: 2개 이상 권장. 분석 대상과 같은 실적기간·같은 주가 기준일이 확보되지 않으면 제외한다.

**현재 주가**: 마지막 확인 가능한 거래일 종가(실시간 체결가 아님). 실행일과 종가일 차이가 7일을 넘으면 검증 실패. 이유: 오래된 주가로 괴리율을 계산하는 것을 막기 위해서다.

### 4-2. 공통 표 규격

15개 열: 종목코드, 종목명, 항목, 값, 단위, 기준, 기준일, 공시일, 출처, 출처 URL, 신뢰도, 수집 방법, 수집 시각, 상태, 비고. 15는 열 개수이며 지표 개수가 아니다. 열 이름이 다르면 명시적 매핑이 필요하고, 단위·연결/별도·기간이 맞지 않는 값은 자동 결합하지 않는다.

### 4-3. 출처카드

- 출처카드: DART 사업보고서·분기보고서·반기보고서 (재무정보, 주식수, 공시접수일)
- 출처카드: 주가 조회처 (현재·과거 종가, 기준일. 코드에서 실제 사용하는 조회처 명칭으로 표기)
- 출처카드: 기업 IR 자료 (부문 실적, 설비투자, 성장 전망)
- 출처카드: 증권사 기업·산업 리포트 (실적 전망, 비교기업, 목표 배수 참고)

IR·증권사 자료는 코드가 자동 수집하지 않으며, 앞선 파트나 사람이 제공한 경우에만 근거로 쓴다.

## 5. 출력

**위치**: 최종 리포트의 `밸류에이션(Valuation)` 섹션. 기본 산출물은 A4 세로 1쪽 요약이다. (고민 중: 전체 리포트 구성에서 이 칸의 분량이 1쪽인지 확인)

1쪽 요약의 구성:

1. 기업 특성과 평가모형 선정(5개 모형 판정, 주력·보조)
2. 현재 배수와 최근 최대 5개 연도의 유효 배수 중앙값 비교(2번 분석 순서의 표본 기준 적용)
3. 최근 최대 5개 연도의 PER 추이 차트 1개(확인된 연도만 표시)
4. 동종기업 배수 비교표 1개
5. 1년 선행 매출·영업이익·EPS 추정과 가정
6. Bear/Base/Bull 주당가치와 괴리율 표 1개
7. 주력 모형 Base 가치와 주요 한계
8. 종합 해석과 검증 포인트

기존 1쪽 요약의 구성에 맞춰 1번의 5개 모형 판정, 4번의 동종기업 배수 비교, 6번의 시나리오별 주당가치·괴리율을 실제 Markdown 표로 작성한다. 1번 표에는 모형, 적합성 및 근거, 실제 산출 상태 및 사유를 적는다. 6번 표는 Bear/Base/Bull 행을 두고 가정, 사용 모형·목표 배수(해당 시), 주당가치, 괴리율을 적는다. 자료가 없는 항목도 표에 남겨 입력은 `미제공`, 결과는 `미산출`과 구체적인 사유로 표시한다. 결측값을 임의 숫자로 채우지 않는다.

**별도 산출물**: 9개 섹션의 상세 HTML 보고서, 원천 재무데이터·출처 목록·TTM 계산내역·모형 판정·가정·시나리오별 계산·검증 로그·미확인 항목(CSV·JSON·텍스트). 검증 로그는 본문에 노출하지 않고 인계자료로만 둔다.

## 6. 멈출 조건

AI는 아래 경우 추측하거나 값을 만들지 않고 "확인 필요" 또는 "보류"로 표시한다.

**전체 중단 (보고서 생성 차단)**

- 종목코드가 유효하지 않거나 기업 식별에 실패
- 필수 재무정보 누락, 연결·별도 기준 불일치
- 공통 엔진 수치가 DART 공식값과 충돌하고 해소되지 않음
- 유효한 주식수를 확보하지 못함
- 정보 마감 이후 공개됐거나 공개 시점을 확인할 수 없는 입력을 제외한 뒤에도 과거 평가의 필수 근거를 확보할 수 없는 경우
- 국내 12월 결산 비금융 상장사·보통주 범위를 벗어남
- 주당가치 독립 재계산 불일치, 산출 가능으로 판정해 적용한 모형의 시나리오 결과 누락, 필수 검증 실패
- AI가 코드 상한을 초과하거나 보류 모형을 주력으로 선택
- 적용한 모형의 Bear/Base/Bull 필수 입력 누락, 경제적 순서·허용 범위 위반
- 제공된 산업 전망이나 기업·재무분석의 근거와 이 파트 가정이 크게 충돌하면 결론을 내지 않고 충돌 내용을 표시

**해당 모형만 보류**

- EPS가 0 이하이거나 확인 불가 → PER만 보류
- DCF·EV/EBITDA의 상세 계정을 검증하지 못함 → 해당 모형만 보류
- 2번과 3-3의 기준을 충족하는 목표 배수의 근거가 부족 → 해당 상대가치 모형의 적용을 보류하고 주당가치를 `미산출(목표 배수 근거 부족)`로 표시한다. 기업 특성상 적합하거나 조건부인 모형은 후보로 설명할 수 있다.
- DCF 사용 시 WACC·영구성장률 근거를 가정 근거에 쓰지 못함 → DCF 보류 (고민 중: 8-3 ④)

자료 부족으로 적용 가능한 모형이 하나도 남지 않아도 확인 가능한 재무 분석, 모형 판정, 근거가 있는 시나리오 가정은 제시한다. 유효한 현재 종가가 없으면 재무 분석 기준일과 실적기간을 명시하고, 시가총액·현재 시장 배수(PER·PBR 등)·괴리율 등 종가 의존 항목만 `계산 불가(유효한 종가 없음)`로 표시한다. 적정주가는 모형별 필수 입력으로 산출 가능 여부를 별도로 판단한다. 극단값과 비필수 데이터의 확인 필요 상태는 경고로 기록하고 보고서 생성은 막지 않는다.

## 7. 계산 규칙 (계산은 코드가 해요)

| 항목 | 공식 | 이 기준을 고른 이유 |
| --- | --- | --- |
| TTM | 직전 연간 + 당기 누적 − 전년 동기 누적 | 결산 시차를 줄여 최신 12개월 실적을 반영. 공시일·기준일이 검증되지 않으면 연간 실적 사용 |
| EPS / BPS | 지배주주순이익(자본) ÷ 보통주 유통주식수 | 종목의 주주 귀속분과 현재 주가의 주식수 시점을 맞춤. 가중평균 주식수와 차이 가능, 별도 표시 |
| PER / PBR | 주가 ÷ EPS / BPS | 이익·자산가치 기준의 표준 상대평가 |
| PSR | 시가총액 ÷ 매출액 | 이익이 불안정하거나 적자일 때 대안 |
| EBITDA, 순차입금 | 영업이익 + 감가상각비, 이자부채 − 현금 | 감가상각·자본구조 차이를 제거해 비교 |
| EV/EBITDA | (시가총액 + 순차입금) ÷ EBITDA | 부채 구조가 다른 기업 간 비교 |
| 예상 실적 | 매출 = 기초 매출 × (1+성장률), 영업이익 = 매출 × 영업이익률, 순이익 = 영업이익 × 순이익/영업이익, EPS = 순이익 ÷ 주식수 | 가정을 매출·마진·전환율로 분해해 검증과 비교 가능하게 함 |
| PER 가치 | 1년 선행 EPS × 목표 PER | 이익창출력 중심 기업에 적용 |
| PBR 가치 | 선행 BPS × 목표 PBR, 선행 BPS = (기초 지배주주자본 + 예상 순이익 × (1 − 배당성향)) ÷ 주식수 | 배당 외 자본 변동이 없다고 단순화 |
| EV/EBITDA 가치 | (선행 EBITDA × 목표 배수 − 순차입금) ÷ 주식수 | 자본구조 차이 반영 |
| DCF | FCFF = EBIT × (1−세율) + D&A − CAPEX − ΔNWC. ΔNWC = 당기 말 영업순운전자본 − 전기 말 영업순운전자본. 기업가치 = 5년 FCFF 현가 + 영구가치 현가. 영구가치 = 5년차 FCFF × (1+g) ÷ (WACC−g). 주당가치 = (기업가치 − 순차입금) ÷ 주식수 | 5년은 명시적 추정 기간이다. 일정한 성장률·마진·재투자율 가정은 적용 시 한계에 명시한다. |
| PSR 가치 | (선행 매출 × 목표 PSR) ÷ 주식수 | 매출 기반 보조 평가 |
| 괴리율 | (추정 주당가치 ÷ 현재 종가 − 1) × 100 | 양수면 현재 주가가 추정가치보다 낮음 |
| 극단값·주가 기준일 | 0.2배 미만 / 5배 초과, 7일 이내 | 3-6, 4-1 참조 |

**괴리율을 Buy/Hold/Sell로 자동 변환하지 않는다.** BUY/HOLD 등 투자의견 기준은 센터장이 정한 기회비용 밴드를 따른다. 기준이 없으면 투자의견을 `확인 필요`로 표시한다.

ΔNWC는 현금성자산과 이자부채를 제외한 영업유동자산·부채를 일관된 기준으로 산정한다. ΔNWC가 양수이면 운전자본에 투입된 현금이므로 FCFF에서 차감한다.

- **ΔNWC=0 적용 조건**: 과거 영업순운전자본 추이와 전망을 근거로 평가 기간의 증감이 중요하지 않다고 판단할 때 단순화 가정으로 사용할 수 있다. 자료가 부족해 0을 검증할 수 없으면 ΔNWC 추정 근거 부족으로 DCF를 보류한다.
- **ΔNWC=0의 한계**: 매출 성장에 따른 재고·매출채권·매입채무 변동의 현금효과가 생략된다. 실제 운전자본이 늘면 FCFF와 가치가 과대 추정될 수 있고, 줄면 과소 추정될 수 있다. 적용 근거와 한계를 보고서에 적는다.

엔진 EPS와 DART 기본 EPS가 다르면 두 값과 차이를 표시하고, 각각의 이익 분자, 주식수 분모, 실적기간, 연결·별도 기준, 주식수 기준일 또는 가중평균 기간을 대조한다. DART 원문 주당이익 주석에서 보통주 귀속이익과 가중평균 유통보통주식수를 확인한다. 원문 주석이 없으면 `원인 확인 필요`로 표시한다. 산식과 기준의 차이로 설명되는 경우에는 그 근거를 기록한다.

### 8-3. 이익 추정 인계 규칙과 고민 중인 항목

**밸류에이션 파트의 자체 전망과 인계**

- 3-4의 기준으로 Base와 Bear/Bull을 수립하고 보고서에 "밸류에이션 자체 전망"으로 표시한다. 각 가정에 전망 기간, 근거가 된 실적기간, 출처와 판단 이유를 적는다. 제공된 외부 전망은 참고 근거로 표시하며, 제공되지 않은 외부 전망치나 기업 고유 사실은 만들지 않는다.
- AI가 제안한 가정과 코드가 계산한 선행 실적·시나리오별 적정가치를 구분해 인계한다. 코드는 기존 입력 허용 범위, 시나리오 순서와 계산 결과를 검증한다. 코드 결과가 없거나 근거가 부족한 경우 5·6번의 결측 표시와 중단 조건을 적용한다.

고민 중 ① 공통 엔진 출력 규격: 통합 엔진의 열 이름과 전달 방식(CSV/DataFrame)이 확정되지 않아 입력 매핑을 최종 확정해야 한다.

고민 중 ② 자체 전망 가정의 전달 방식: 밸류에이션의 시나리오별 가정과 출처를 계산 코드에 전달할 형식을 정해야 한다.

고민 중 ③ 계산 도구와의 역할 구분: v8 안에 지표 계산과 가치평가 함수가 있어, 전체 엔진의 계산 도구와 중복되지 않도록 계산 책임 모듈을 정해야 한다.

고민 중 ④ WACC·영구성장률 근거: 현재는 AI가 범위 안에서 제시한다. 무위험이자율·베타·위험프리미엄 같은 산출 근거 입력을 둘지 정해야 한다.

## 10. 그 밖에

**AI와 코드의 역할 분리**

- 코드: DART·주가 수집, 공통 표 검증, 지표 산출, 모형 상한 판정, 시나리오별 주당가치 계산, 독립 재검산, 보고서 생성
- AI: 상한 안에서의 적합성 판단, 주력·보조 선정, 시나리오 가정 제안, 결과 해석. 입력된 재무 수치를 바꾸거나 계산 결과를 새로 만들지 않는다.
- 사람·검증관: 비교기업 적절성, 미래 추정의 합리성, 경제적 해석, 투자의견 타당성 검토

**재시도**: AI 호출의 일시적 서버 혼잡·타임아웃·일시 제한은 기본·예비 모델을 번갈아 5초부터 최대 120초까지 간격을 늘려 재시도한다. 인증 오류, 잘못된 요청, 영구 할당량 초과는 재시도하지 않고 중단한다.

**재현성**: 정보 마감 시점, 자료 기준일과 실제 공개일시를 기록한다. 실행 코드가 제공하는 CSV·JSON·검증 로그로 원천과 가정을 추적한다. 검증 통과는 수치·형식·규칙 충족을 뜻할 뿐, 목표 배수나 성장률의 경제적 타당성이 입증됨을 뜻하지 않는다.

**적용 범위와 한계**

- 국내 12월 결산 비금융 상장사, 보통주
- 최신 확인 가능한 종가 사용(실시간 체결가 아님)
- 동종기업 선정은 상위 분석 또는 사용자 입력에 의존
- 사업부문별 매출은 자동 수집·분해하지 않음
- v8 참고 구현은 DCF에서 ΔNWC=0을 사용한다. 적용 조건과 한계는 7번을 따르고, 분석에 필요한 ΔNWC를 실행 코드가 반영할 수 없으면 DCF를 보류한다.
- 과거 연말 배수는 사후 확정 실적을 쓴 참고값
- 실제 증권사 컨센서스와 AI의 시나리오 가정은 별개

이 모듈은 모든 기업의 적정주가를 산출하는 것이 아니라, 확인된 데이터 범위 안에서 적용 가능한 모형을 고르고 가정과 한계를 명시하는 검증 중심 밸류에이션이다.
